# 박상순부동산 · 노원구 아파트 대시보드

## 사용법
- **보기**: `index.html` 더블클릭 (또는 `대시보드_실행.bat` → http://localhost:8080)
- **데이터 최신화**: `데이터_업데이트.bat` 실행 (약 2분, 신규 단지 좌표 검색 시 추가 소요) → 브라우저 새로고침
- Node.js 설치 필요 (데이터 업데이트·로컬 서버용)

## 화면 구성
| 영역 | 내용 | 출처 |
|---|---|---|
| 상단 필터 | 동 선택(상계·중계·하계·공릉·월계), 주간/월간 집계, 기간 직접 지정·프리셋 | – |
| KPI | 매매 거래량·평당가, 전세 평당가, 월세 평균, 주간 매매지수, 전세가율·미분양 | 국토부 실거래가, 한국부동산원 |
| 차트 | 거래량·평당가 추이, 가격지수(노원/동북권/서울/전국), 매매수급지수, 월간 평균가·전세가율·거래량 | 〃 |
| TOP10 + 지도 | 매매/전세/월세 탭, 거래량·평당가·최고가 순위, 선택 단지 위치·최근 실거래, 반경 1km 지하철·학교·마트 | 실거래가 + OpenStreetMap |
| 추천매물 | 샘플 4건, `+ 매물 등록`으로 추가(브라우저에 저장), 동일평형 최근 실거래 비교 | 직접 입력 |
| 입지분석 | 교통(지하철·KTX/SRT/GTX·버스), 학군(초·중·고·학원가), 상권(백화점·마트·카페·관공서·병원·공원), 개발계획 | OpenStreetMap + `assets/static.js` |
| 아파트 리스트 | 선택 동의 전체 단지, 정렬·검색, 클릭 시 지도/입지분석 | 실거래가 |

## 파일
- `scripts/config.json` – API 키 (git 제외됨. `config.example.json`을 복사해 키 입력)
- `scripts/fetch_data.mjs` – 데이터 수집 (국토부 매매·전월세, 부동산원 R-ONE, 좌표, 주변시설)
- `assets/static.js` – 지하철 노선, 광역교통, **개발계획**, **추천매물 샘플** (직접 수정 가능)
- `data/` – 수집된 데이터 (자동 생성)

## 참고
- 추천매물 등록 내용은 사용 중인 브라우저(localStorage)에만 저장됩니다.
- 단지 좌표는 도로명주소 지오코딩(OpenStreetMap) 결과로, 일부는 근사 위치일 수 있습니다.
- 개발계획은 2026년 공개자료 요약이므로 브리핑 전 최신 일정을 확인하세요.
